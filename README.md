# SMS Yuboruvchi

Excel (.xlsx) yoki CSV fayldagi raqamlarga telefon SIM-kartasi orqali ommaviy SMS yuboradi.

Excel formati: 1-ustun — telefon raqami, 2-ustun (ixtiyoriy) — ism. Sarlavha qatori bo'lsa o'tkazib yuboriladi.

APK yig'ish: GitHub'ga yuklang -> Actions -> Build APK -> Artifacts -> SmsSender-apk.
